# Snake Game

## Instructions for Compiling and Running

1. **Clone the repository**:
   ```bash
   git clone https://github.com/prapto7457/sir.git
   cd sir
   ```

2. **Install dependencies**:
   Make sure you have the necessary libraries installed. You can do this by running:
   ```bash
   # Replace with the appropriate command for your package manager
   sudo apt-get install <required-libraries>
   ```

3. **Compile the game**:
   Use the following command to compile the source code:
   ```bash
   gcc -o snake game.c
   ```

4. **Run the game**:
   After compiling, you can run the game by executing:
   ```bash
   ./snake
   ```

## Enjoy the Game!
